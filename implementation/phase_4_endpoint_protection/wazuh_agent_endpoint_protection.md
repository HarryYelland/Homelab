## Endpoint Protection & Visibility

### Objective
Extend security monitoring and detection capabilities to user endpoints by deploying host-based agents and enforcing consistent network inspection across devices.

---

### Endpoint Security Architecture

Endpoint protection was implemented using the Wazuh agent on user-operated devices, specifically:
- A Windows PC
- A macOS laptop

Agents communicate with the Wazuh Manager over the ZeroTier network, providing encrypted and authenticated telemetry transport without exposing management services externally.

---

### Windows Endpoint Integration

The Windows endpoint was onboarded using the Wazuh agent to provide deep host-level visibility that cannot be achieved through network controls alone.

Collected telemetry includes:
- Windows Security, System and Application event logs
- Authentication and authorisation events
- File integrity monitoring of critical system and user-accessible paths
- Process execution and PowerShell operational activity
- Installed software and vulnerability data

---

### macOS Endpoint Integration

The macOS endpoint was integrated using the Wazuh agent with configuration aligned to macOS logging and filesystem behaviour.

Monitoring includes:
- Security-relevant unified log events
- File integrity monitoring of Applications and user download directories
- Process execution and software inventory tracking

In this part of the implementation, I found issues with the agent event queue flooding - see my troubleshooting section for more information on how this was resolved.

---

### Network Enforcement on Endpoints

To ensure endpoint activity aligned with the network security stack, client devices were configured to:
- Use Pi-hole as their DNS resolver
- Route HTTP and HTTPS traffic through the Squid proxy

This ensured:
- DNS queries generated by endpoints were logged and enforceable
- Web traffic could be inspected for malicious content
- Endpoint events could be correlated with proxy and DNS activity in the SIEM

---

### Outcome

Successfully extended the security monitoring perimeter to user endpoints, providing:
- Host-based detection on Windows and macOS
- Visibility into endpoint execution, authentication and file changes
- Correlation between endpoint behaviour and network-layer events
- Centralised alerting and investigation via the SIEM
